# Vectors (vetores)

## O que guarda

esta pasta guarda teste com vetores em C++

## Projeto 1 (main.cpp)

projeto para entender como funcionam os vetores em C++ e funcionalidades como a criação dos vetores em si, push_back() e percorrer o vetor com laço for.

## Projeto 2 (vectorsman.cpp)

Projeto que bota em prática os conteúdos do primeiro projeto em um tipo de CRUD primitivo (porém sem o update).

## Projeto 3 (structman.cpp)

Projeto que melhora o `vectorsman.cpp` com o uso de structs e depois vetores. basicamente igual ao anterior, mas agora com update e melhoras na lógica de programação para C++.

## Projeto 4 (todolist.cpp)

Último projeto até agora desta pasta. trabalha vetores com mais detalhes e melhor lógica. trabalha com estrutura lógica (if e else) e laços de repetição for para percorrer vetor, e while para menu, assim como nos anteriores.
